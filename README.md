# Микротопонимы окрестностей аргуновских деревень

Карта микротопонимов Аргуновской волости создана в Конструкторе Яндекс Карт. Названия и первоначальное размещение объектов перенесены по карте из книги Н. В. Большаковой. Этот репозиторий предназначен для хранения данных карты, истории изменений и обсуждения уточнений с участниками краеведческого сообщества.

## Источник

Большакова Н. В. *Древнее Аргуново*. — М.: Компания «Спутник+», 2004. — 224 с. — ISBN 5-93406-647-1.

Источник картографических данных: «Рис. 1. Карта микротопонимов к окрестностям аргуновских деревень» (подпись приведена по сообщению составителя карты). Страницу с рисунком и точную подпись следует сверить по экземпляру книги перед окончательным оформлением ссылки.

## Как читать карту

Координаты нанесённых объектов — результат переноса сведений с опубликованной карты на современную подложку Яндекса, а не измерения, выполненные Н. В. Большаковой. Если место нельзя определить однозначно, его положение следует считать приблизительным. Исходное название и предлагаемые варианты написания лучше сохранять раздельно, не заменяя одно другим без пояснения.

## Как предложить исправление

Сообщите название объекта, что именно нужно исправить и почему. По возможности приложите страницу книги или ссылку на иной источник, а для изменения положения — объяснение, как определено новое место. Правки можно обсуждать через GitHub Issues или предлагать через pull request; после проверки они включаются в основной файл карты.

## О версиях

История изменений файлов хранится в GitHub. Карта в Конструкторе Яндекс Карт не синхронизируется с репозиторием автоматически: после принятия правок обновлённый файл нужно отдельно проверить и импортировать в Конструктор. Оригинальный экспорт карты рекомендуется хранить как резервную копию.

## Использование материалов

Библиографическая ссылка указывает источник сведений и не означает, что текст или иллюстрации книги свободны для перепубликации. Если в репозиторий планируется загрузить скан рисунка, вопрос прав на его публикацию нужно проверить отдельно.
